# Code of Conduct

## Introduction

This project adopts the [Amazon Open Source Code of Conduct](https://aws.github.io/code-of-conduct). All participants are expected to follow its guidelines in every project space, including issues, pull requests, and community discussions.

For more information, see the [Code of Conduct FAQ](https://aws.github.io/code-of-conduct-faq) or contact
opensource-codeofconduct@amazon.com with any additional questions or comments.

## Conclusion

Respectful, inclusive collaboration makes this project better for everyone. If you have questions about expected conduct or need to report an issue, contact opensource-codeofconduct@amazon.com.
